# ATH Móvil PHP v0.1.0-alpha.1

First **MIT-licensed development preview** of `gatomontes/athmovil-php`.

**Live ATH Móvil payments and refunds remain unverified.** Live credentials were unavailable. This release is intended for development and evaluation; automated simulation checks do not establish production compatibility. The package is unofficial and is not endorsed by Evertec.

## What you can try

- Use the PHP client to create/find/authorize/cancel payments, update phone numbers, and request refunds.
- Complete a local checkout using your actual submitted items and payment/item metadata.
- Inspect clearly fictional Test Payer details in documented customer response fields.
- Simulate confirmation, cancellation, expiration, rejection, and lost responses before or after processing.
- Exercise partial/full refunds, persistent sessions, per-business state isolation, and captured request/response history.
- Run the CLI example or the browser demo in `examples/checkout/`.

## Validation

The publishing job runs only after the PHP 8.2–8.5 test matrix passes: Composer validation, PHP syntax, 38 client/simulation tests, the CLI demo, a loopback HTTPS transport smoke test, and the checkout HTTP test including server restart persistence. The owner also reported a successful Windows local test/demo run.

## Install before Packagist registration

Add this repository and explicit alpha constraint to your application's Composer configuration:

```json
{
  "repositories": [{"type": "vcs", "url": "https://github.com/gatomontes/athmovil-php"}],
  "require": {"gatomontes/athmovil-php": "0.1.0-alpha.1"}
}
```

Then run `composer update gatomontes/athmovil-php`. Merge the settings into your existing configuration.

To explore the repository locally:

```sh
git clone --branch v0.1.0-alpha.1 https://github.com/gatomontes/athmovil-php.git
cd athmovil-php
composer install
composer test
php -S 127.0.0.1:8765 -t examples/checkout/public
```

Open http://127.0.0.1:8765. The browser demo is simulation-only.

Public APIs may change before stable release. See `docs/api-contract.md` for upstream inconsistencies and simulator assumptions. Report issues with synthetic or redacted examples; do not attach credentials or raw customer data.
